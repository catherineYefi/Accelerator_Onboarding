# Акселератор — онбординг участника

Одностраничный онбординг первого потока: старт и чек-лист, маршрут по датам, воркбук, бонусы, материалы.

## Как обновлять

Все тексты, даты и ссылки — в одном файле `src/data/content.js`.

- Ссылка `null` → на странице кнопка «скоро». Вставьте адрес в блок `links` — кнопка заработает.
- Даты встреч — в `events`, этапы — в `stages`.
- После изменения в ветке `main` сайт пересобирается и публикуется сам (GitHub Actions → ветка `gh-pages`).

## Служебные параметры адреса

- `?draft` — режим черновика: подсвечены пустые ссылки, внизу кнопка со списком того, чего не хватает.
- `?today=2026-12-10` — показать страницу так, как она выглядит в выбранный день.
- `#/route/rnp` — ссылка сразу на этап маршрута (`org`, `rnp`, `pl`, `decomp`, `finplan`, `finmodel`, `ss`, `final`). Разделы: `#/start`, `#/route`, `#/workbook`, `#/bonuses`, `#/materials`.

## Локально

```
npm install
npm run dev
```
